# Source-to-design coverage

This map proves that the normalized design did not discard source material. “Owner” names the live
document that carries the idea. “Disposition” is a routing summary; the owning document contains
the precise delivered, backlog, or OBE rows. References point to archived wording.

<a id="coverage-method"></a>

## Coverage method

Later sources supersede only conflicting ideas. Implemented mechanics, current evidence, and
future intent are separated. Historical estimates and exact weights remain in the archive when
they should not govern future work. References and biological arguments stay with their mechanism
in the normalized documents.
