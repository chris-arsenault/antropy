> [current results](numerical-results.md) and [migration dispositions](numerical-migration.md)

Execution record, September 13, 2026. The shared replacement and content migration are implemented; human motion/operating acceptance remains open. Historical measurements
keep their original chemistry, schema and conclusions. A migrated command is not a repeated
experiment, and an executable fixture is not evidence that its hypothesis succeeds.

## Removal and provenance checks

The active TypeScript path contains no old A/B field, named toxin/matrix, reserve-to-energy,
carbon/oxygen, direct prey-yield or automatic-sharing owner. References to retired flag names and
old versions are explicit rejection tests/parser errors. Retained filenames such as
`FoodEpochSettings` now own generic source composition only; they contain no former chemical rule.
Historical Python readers interpret saved artifacts and never advance simulation.

Current checkpoints reject surplus nested genotype/controller/machinery/property fields as well as
old top-level state and configuration. The obsolete manual-save fallback was removed without
deleting its IndexedDB store or saved data. Frozen inherited comparisons explicitly disable contact
transfer/selfing to keep cohort/genotype denominators valid.

The original current documentation was copied intact to the
[pre-chemistry snapshot](../../sources/history/README.md). Runtime, controller, body, ecology,
calibration, observation, development, agent guidance and indexes now describe this replacement.
Historical studies retain original data and corrected conclusions; schema-v2 results are separate.
No migration campaign, browser server, commit/push or hosted publication was performed.

## Remaining acceptance

The main implementation and local checks do not close human acceptance. The initial throughput
was rejected; [performance work](population-performance.md) now measures 52.6 ticks/s through
tick 2,000 at 48 founders, with a 44.5 minimum window, 82-ms encoding and 297-ms restore.
The full final checkpoint matches the slower 48-founder audit. [Viability repairs](viability.md)
were tested with small causal probes and repeated daughter reproduction; this default reaches
74 cells and ends at 57 with generation four. The eight-founder acceptance claim is withdrawn.
The user already runs a development server. Human review of motion,
source visibility, zoom and recovery remains open. Long-term diversity, successful colonization
and days/weeks endurance are not claimed.
