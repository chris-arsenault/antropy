# 0010 — Seed portfolio derived by direct optimization, baked as artifacts

- Status: Accepted
- Date: 2026-09-02

## Context

Hand-written instinct weights repeatedly did not implement what they were believed to
implement (Release 2's traced defects; §B.6 item 5, §B.9.3). Appendix B prescribes deriving
founder seeds by direct optimization (CMA-ES) against probe tasks, and the same probe
doubles as the architecture's empirical capacity ruler (§B.2.4). The optimizer must not
become a runtime dependency of the simulation.

## Decision

An in-house (μ/μ, λ) evolution strategy with diagonal covariance adaptation (sep-CMA-lite,
no external dependency) optimizes controller weights against episodic probe tasks
(gradient-following, homing, satiation-gated pickup, reflexive digging, trail deposit and
follow). Derivation runs as a dev-time harness; the resulting portfolio seeds are baked
into a committed generated artifact that `seed()` draws from. Simple reflexive seeds may
still be written constructively when the rung-3 assay proves them; composite seeds are
always derived. The run itself keeps no fitness function — initialization is allowed to be
smart (§B.9.3).

## Alternatives considered

- **Full CMA-ES** — the letter of §B.9.3, but full covariance adaptation needs
  eigendecomposition machinery disproportionate to fitting reflex-scale tasks in ≤600
  dimensions; diagonal adaptation fits them and stays ~100 lines. Revisit if probes fail
  to fit (which is itself the §B.2.4 capacity signal).
- **Hand-written seeds only** — empirically failed four times in Release 2; every failure
  cost a traced-debug cycle. Rejected as the default (retained for provably trivial
  reflexes with assays).
- **Derive at world creation** — keeps seeds fresh but puts minutes of optimization on the
  runtime path and makes worlds non-reproducible across code versions. Rejected.

## Consequences

- The committed seeds file is a generated artifact (like a lockfile): regenerated by the
  derivation harness, reviewed by its assay gates, never hand-edited.
- Probe fit/failure per hidden width becomes the standing answer to "is capacity the
  problem" (§B.2.4's one-way test).
